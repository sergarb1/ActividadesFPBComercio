3 · RECETA PARA CREAR CADA UNIDAD NUEVA (15, 16, 17...)
-------------------------------------------------------
1. Carpeta + 4 ficheros markdown:
   src/content/docs/NN-nombre.md                     (índice)
   src/content/docs/NN-nombre/01-....md              (ficha 1)
   src/content/docs/NN-nombre/02-....md              (ficha 2)
   src/content/docs/NN-nombre/03-juegos-y-retos.md   (ficha 3)
2. Frontmatter SIEMPRE con comillas si el texto lleva dos puntos:
   title: "15 — ..." · description: "..."  (un title con ":" sin comillas
   rompe el build con un error YAML neutro tipo "Nested mappings").
3. Índice: mapa del bloque, objetivo, tabla del mapa de la unidad,
   ejercicio-links, ¿por dónde empiezo? y pie Anterior/Siguiente
   (SOLO enlazar paginas existentes; el build falla con enlaces rotos).
4. Fichas: formato del punto 1; ejercicios en <div class="ejercicio">,
   respuestas en <details>, ≥1 fail de DANI en la ficha 3, tono
   cooperativo (ROSA se ríe de la tontería, nunca del compañero).
5. 2 imágenes Excalidraw por unidad:
   - Copiar scripts/gen-tienda-14.py y cambiar escenas/nombres
     (reutiliza helpers de gen-tienda-images.py).
   - python scripts/gen-tienda-NN.py
   - mkdir -p public/img/NN-nombre  (¡sin acentos en el nombre!)
   - npx -y mcp-excalidraw-server render public/img/fuentes/NN-...-ficha1.excalidraw \
       --format svg --out public/img/NN-nombre/01-....svg
     (y PNG igual). Ojo: si un texto es un párrafo largo, hay que
     envolverlo en \n a mano o el SVG sale 2000px de ancho.
   - Poner en el <img> las dimensiones reales del viewBox (salen en el
     propio resultado del render).
6. Registrar en astro.config.mjs (grupo del sidebar), landing
   (src/content/docs/index.md, tarjeta en la sección del bloque) y
   enlazar "siguiente" en la unidad anterior.
7. Actualizar AGENTS.md (Estado actual + fila del temario) y HANDOFF.md.
8. Checks: npm run build (capturar exit) · npm run docx (los DOCX van al
   repo) · grep de enlaces contra dist/ (dist/NN-slug/... no lleva el base
   delante) y rutas img contra public/img/ · commit · push ·
   gh run watch + curl a las 4 URLs nuevas (con barra final: sin barra
   GitHub Pages responde 301).
