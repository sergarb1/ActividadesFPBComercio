## 📬 En corto

> Una tabla mal diseñada envenena el torneo: si solo gana "el más listo", sobra. La tabla correcta premia **constancia, rotación y cooperación**, y el premio final lo decide el grupo entero con voto.

---

## 💡 Lo que hay que saber

**La tabla (una fila por semana, una columna por equipo):**

| Semana | Dinámica jugada | Equipo 1 | Equipo 2 | Equipo 3 | Equipo 4 | Observaciones |
|---|---|---|---|---|---|---|
| 1 · Mostrador | Guion de 5 pasos | | | | | |
| 2 · Caja | Cambio a contrarreloj | | | | | |
| 3 · Almacén | Recepción a contrarreloj | | | | | |
| 4 · Stock | Turno imposible | | | | | |
| 5 · Variado | Mostrador a ciegas | | | | | |
| … | | | | | | 🏁 La final: puntos dobles |

**Reglas de la tabla:**

1. **La escribe el contador de cada equipo** (con revisión cruzada de otro equipo: no hay nada oculto).
2. **Los puntos se cuentan en voz alta** al terminar la dinámica: nadie los descubre una semana después.
3. **Punto doble la final:** la última semana vale x2, así llegar por detrás no es perder antes de empezar.
4. La columna **Observaciones** anota solo cosas de **procedimiento** ("faltó rotación"), nunca nombres.

**Los premios cooperativos (se eligen con voto en la semana 0):**

| Nivel | Ejemplo de premio |
|---|---|
| 🥇 Equipo ganador | Elige **qué dinámica** se juega en la final + música del aula durante la quincena |
| 🥈 Segundo | Eligen **tema libre** para la última dinámica |
| 🤝 Premio "equipazo" | Al equipo que más rotación y más veces "Nadie fuera" acumule: es **el premio de verdad** |
| 🌟 Premio al fallo bien tomado | Al equipo que mejor lleve el fail de DANI: se vota por escrito y no se nombra a nadie en voz alta |

⚠️ **Nunca:** notas, dineros, exenciones de deberes o "no me toca" como premio. Eso compra participación con moneda falsa: se muere cuando el premio no está.

## 🎭 Mini dinámica: la subasta de premios (10 min)

Cada equipo reparte 10 "monedas de proyecto" entre los 4 premios de su lista. Se cuentan los votos y gana una carta de premios puesta por partes. Se aprende a **negociar** lo que quiere el grupo, no lo que quiere el más voteador.

> ♿ **Inclusión:** la subasta se puede hacer por papeleta escrita y legible; quien no vote en voz alta no pierde el voto.

---

## 🔑 Para el profe

- Pega la tabla **donde todo el mundo la ve** (no detrás de la pizarra ni solo en digital): el torneo vive de verse.
- El punto "Observaciones" es tu herramienta de clima: be nota procedimiento, no nombres. Si aparecen nombres, se borra en el momento sin dramatismo.
